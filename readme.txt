Minimal plugin used to test git-based continuous delivery to the WordPress.org SVN repository.

== Description ==

Minimal plugin used to test git-based continuous delivery. Implements activation and deactivation modes only.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/git-cd-testing` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
